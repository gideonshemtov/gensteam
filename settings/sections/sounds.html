Sound Settings
Enable or disable all sound playback for MUD triggers
Master volume control for all sounds
🔇 🔊
View configured sound names to file mappings. Place sound files in the assets/sounds/ directory. Use these names in your MUD triggers with mudAPI.playSound("soundName"). To modify sound mappings, use the JSON editor.

Use the following JavaScript in your MUD client triggers to play sounds:

// Play a configured sound by name
mudAPI.playSound("alert");
// Play a sound file directly with volume
mudAPI.playSoundFile("combat.wav", 0.8);
// Test if sound is available
if (await mudAPI.playSound("whisper")) {
  // Sound played successfully
}

Supported formats: .wav, .mp3, .ogg, .m4a, .aac, .flac
